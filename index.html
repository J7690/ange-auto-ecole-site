Nos Catégories de Permis

Découvrez les différentes catégories de permis de conduire que nous proposons au Burkina Faso

🏍️

Permis A1

Âge minimum : 14 ans

Véhicules : Vélomoteurs et cyclomoteurs (≤125 cm³, ≤11 kW)

Description : Motocycles légers avec ou sans side-car

🏍️

Permis A

Âge minimum : 16 ans

Véhicules : Motocycles (>125 cm³)

Description : Motocycles avec ou sans side-car

🚗

Permis B

Âge minimum : 18 ans

Véhicules : Automobiles (PTAC ≤3500 kg, ≤8 places)

Description : Voitures particulières et véhicules légers

🛵

Permis B1

Âge minimum : 16 ans

Véhicules : Tricycles et quadricycles à moteur

Description : Véhicules à trois ou quatre roues

🚚

Permis C

Âge minimum : 18 ans

Véhicules : Transport de marchandises (PTAC >3500 kg)

Description : Camions et véhicules utilitaires
