# Dossier Assets

Ce dossier contient tous les fichiers multimédias du site web.

## Structure

### 📁 images/
Placez ici les images pour le carrousel de la page d'accueil.
- Format recommandé : JPG ou PNG
- Dimensions recommandées : 1920x600 pixels
- Nommez les fichiers : image1.jpg, image2.jpg, image3.jpg, etc.

### 📁 logo/
Placez ici le logo de l'auto-école.
- Format recommandé : PNG avec fond transparent
- Dimensions recommandées : 200x200 pixels
- Nom du fichier : logo.png

### 📁 icons/
Placez ici les icônes personnalisées (optionnel).
- Format recommandé : SVG ou PNG
- Nommez les fichiers selon leur usage

## Instructions

1. **Carrousel d'images** : Ajoutez vos images dans le dossier `assets/images/`
2. **Logo** : Ajoutez votre logo dans le dossier `assets/logo/`
3. Une fois les images ajoutées, le site les affichera automatiquement

## Nom des fichiers attendus

Pour le carrousel (au moins 3 images recommandées) :
- assets/images/Image1_ANGE.jpeg
- assets/images/Image2_ANGE.jpeg  
- assets/images/Image3_ANGE.jpeg (optionnel)
- assets/images/Image4_ANGE.jpeg (optionnel)
- assets/images/Image5_ANGE.jpeg (optionnel)

Format alternatif supporté :
- assets/images/image1.jpg
- assets/images/image2.jpg
- assets/images/image3.jpg

Pour le logo :
- assets/logo/LOGO_ANGE.png
